# Mico 🖥️

**Mico** is a collaborative PHP project developed by three contributors:  
- **Tornike Khutsishvili**  
- **lukagiorgilomidze**  
- **Shota-Bliadze**

The project showcases a modular, maintainable architecture combining **PHP, SCSS, CSS, and JavaScript**. It focuses on dynamic web application development with responsive design principles.

## Features
- Modular PHP components for easy maintenance  
- Responsive design using SCSS and CSS  
- Interactive UI enhancements with JavaScript  
- Team-based development workflow with multiple branches  
- Deployment-ready for production environments
